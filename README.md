## Data & scripts

- `data/duties.csv` / `data/duties.json` — one row per person per duty
- `scripts/parse_roster.py` — extracts duties from the roster PDF using its cell borders (so merged date/time/venue cells are matched correctly)
- `scripts/build_markdown.py` — builds these Markdown files

Regenerate: `python3 scripts/parse_roster.py roster.pdf data/duties.json && python3 scripts/build_markdown.py data/duties.json .`
